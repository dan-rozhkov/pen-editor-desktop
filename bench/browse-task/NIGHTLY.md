# Ночное улучшение browser use — чек-лист

Источник правды для ночных кронов. Один проход = один пункт. Статусы: `open`, `in-progress`, `done (<SHA>)`, `blocked (<причина>)`.

## Правила
- Исправление общее: без имён сайтов, классов CSS и доменных слов.
- Сценарий можно менять, только если цель доказанно невыполнима (живая проверка). Иначе нельзя.
- Не снижать пороги тестов. Не трогать прод-env. Не бронировать и не покупать.
- Пункт упал дважды → `blocked`, перейти к следующему.
- Порядок пуша: десктоп → `npm run browser:sync` в бэкенде → бэкенд → фронт.
- Бэкенд проверять `npm run test:coverage`. Фронт — с `NODE_OPTIONS=--no-experimental-webstorage`.
